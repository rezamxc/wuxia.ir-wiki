## 📖 درباره پروژه

این پروژه یک **دانشنامه تعاملی، مدرن و جامع به سبک Fandom Wiki** است که از دل تحلیل و استخراج هوشمند **بیش از ۲۰۰۰ فصل از رمان عظیم «شورشی جاودان» (Renegade Immortal - 仙逆)** پدید آمده است.

با استفاده از معماری نوین مهندسی آنتولوژی (Ontology Engine) و هوش مصنوعی، تمام لایه‌های داستان شامل سرگذشت شخصیت‌ها، القاب، دگرگونی وضعیت‌های زیستی، نردبان قلمروهای تهذیب، سلاح‌های باستانی، فنون رزمی و شبکه‌های تبارشناسی با مستندات دقیق فصلی استخراج و به صورت یک وبسایت استاتیک فوق‌سریع و بدون لگ پیاده‌سازی شده است.

> 🌐 **پایگاه اصلی رمان‌های فانتزی و ترجمه:**  
> جهت مطالعه فصول کامل، ترجمه‌ها و اخبار جهان رمان‌های شیان‌شیا و ووشیا، به سایت مرجع **[Wuxia.ir](https://wuxia.ir)** مراجعه فرمایید.

## ✨ قابلیت‌ها و ویژگی‌های کلیدی

### ۱. 📜 خط زمانی رویدادمحور و وقایع سرنوشت‌ساز (Chronological Trajectory)
* ثبت پیوسته تحولات زندگی کاراکترها از فصل ۱ تا فرجام داستان.
* تفکیک وقایع با نشان‌های دقیق: **نخستین معرفی**، **جهش قلمرو**، **تغییر فرقه**، **واقعه سرنوشت‌ساز** و **مرگ**.
* ثبت سن کاراکتر و جزئیات ظاهری و کالبد در همان فصل خاص (پرهیز از پرش زمانی).

### ۲. 🔗 شبکه تبارشناسی و فیلتر پیشرفته ۸‌گانه روابط
گراف چندبُعدی روابط میان شخصیت‌ها با قابلیت فیلتر تفکیکی در ۸ دسته استاندارد:
1. **👨‍👩‍👧 خانوادگی و نسبی (Family):** پدر، مادر، همسر، فرزند، پسرعمو و نیاکان.
2. **🎓 استاد و شاگردی (Mentorship):** استاد، شاگرد، برادران ارشد و هم‌مکتبی‌ها.
3. **🤝 اجتماعی و رقابتی (Social):** دوست، رقیب، هماورد، همراه و حامی.
4. **🏯 سازمانی و فرقه (Political):** عضو فرقه، رئیس فرقه، ارباب، خادم و تابعین.
5. **⚔️ رزمی و معنوی (Spiritual):** مالک سلاح، روح همراه سلاح و تسلط بر مهارت.
6. **🪞 هویت و کالبد (Identity):** کالبد دوم (کلون)، تناسخ، تجسد و هویت‌های تسخیرشده.
7. **📜 روایی و حوادث (Narrative):** قاتل و مقتول، منجی و نجات‌یافته، اسیر و رباینده.
8. **🌐 همه پیوندها (All):** نمایش تجمیعی همراه با ذکر دقیق علت و شماره فصل هر تحول.

### ۳. ⚡ نردبان و سلسله‌مراتب قلمروهای قدرت (Cultivation Realm Ladder)
* طبقه‌بندی دقیق نردبان قدرت (فانی ⬅️ تراکم چی ⬅️ بنیادگذاری پی ⬅️ تشکیل هسته ⬅️ روح نوزاد ⬅️ مبدل به روح و بالاتر).
* نمایش همزمان **قلمرو ورود** و **قلمرو اوج/کنونی** کاراکتر به همراه شمارش تعداد جهش‌های ثبت‌شده.
* فیلتر آنی کاتالوگ برای مشاهده افراد حاضر در هر سطح از قدرت.

### ۴. 📋 جعبه شناسنامه ثابت فندوم (Sticky Infobox)
* خلاصه‌ای جامع از مشخصات بیولوژیک (جنسیت، سن، وضعیت زیستی).
* مشخصات فنی گنجینه‌ها و فنون (رتبه فنی، طبع و عنصر، اثر و کارکرد اصلی).
* محدوده دقیق فصول حضور و ثبت القاب مستعار.

### ۵. 🚀 معماری استاتیک فوق‌سریع و بدون لگ (Zero-Lag Jamstack)
* حل قطعی مشکل کرش کردن مرورگر در پردازش ده‌ها هزار موجودیت از طریق تقسیم دیتا به فایل‌های سبک JSON.
* جستجوی زنده (Live Search) در هدر با سرعت پاسخ‌دهی زیر ۲ میلی‌ثانیه.
* هاستینگ رایگان، ابدی و ایمن روی بستر **GitHub Pages** با اتصال ساب‌دامین و گواهی SSL.

## 🛠️ پشته فناوری (Tech Stack)

| بخش | ابزارها و فناوری‌ها |
| :--- | :--- |
| **فرانت‌اند** | HTML5, Tailwind CSS (Dark Modern Theme), Vanilla JavaScript (ES6+) |
| **طراحی ظاهری** | Fandom Wiki Layout, RTL Native, Responsive Typography (Vazirmatn) |
| **پایگاه داده اصلی** | SQLite 3 (با معماری Event-Sourcing و Bitemporal History) |
| **اکسپورتور دیتا** | Python 3 (تبدیل خودکار دیتابیس به کاتالوگ اتمیک و JSON های مجزا) |
| **استخراج هوشمند** | Google AI Studio Engine (Gemini Pro) با پرامپت مهندسی‌شده آنتولوژی |
| **میزبانی (Hosting)** | GitHub Pages + Cloudflare / Custom DNS |

## 📂 ساختار پوشه‌ها و فایل‌ها

```text
├── index.html            # لندینگ پیج اصلی فندوم، نردبان قدرت و کاوشگر سریع
├── wiki.html             # صفحه اختصاصی مقاله فندوم (شناسنامه، خط زمانی و روابط)
├── export_static.py      # اسکریپت پایتون استخراج دیتابیس SQLite به فرمت استاتیک
├── novel_knowledge.db    # پایگاه داده جامع و مرجع استخراج‌شده از رمان
├── .nojekyll             # دستور به گیت‌هاب جهت خواندن مستقیم تمام فایل‌ها و پوشه‌ها
└── data/
    ├── stats.json        # آمار تجمیعی و نردبان مراحل قدرت
    ├── catalog.json      # کاتالوگ خلاصه برای جستجو و صفحه‌بندی سبک
    └── entities/         # پایگاه داده مجزای هر کاراکتر/گنجینه (مثال: 王林.json)
